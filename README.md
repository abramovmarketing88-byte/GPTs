# Модульный AI-пайплайн для маркетинговых лендингов

## Что делает система

Этот проект преобразует набор промптов в расширяемый Python-пайплайн:

1. Анализирует аудиторию.
2. Выполняет сегментацию.
3. Выявляет боли и барьеры.
4. Синтезирует инсайты.
5. Строит структуру лендинга.
6. Генерирует копирайтинг.
7. Проводит финальную ревизию текста.

Архитектура разделена на **skills** (один шаг = один модуль) и **orchestrator** (управление последовательностью шагов).

## Установка

1. Убедитесь, что установлен Python 3.10+.
2. (Рекомендуется) создать виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate  # Linux/macOS
```

3. Зависимости не обязательны для mock-режима (по умолчанию).

## Запуск

Минимальный запуск:

```bash
python runner.py "Avito marketing service"
```

Запуск с промежуточными шагами:

```bash
python runner.py "Avito marketing service" --show-steps
```

## Как добавить новый prompt (новый шаг)

1. Добавьте файл промпта в `prompts/` (на английском).
2. Создайте skill-модуль в `skills/` с функцией:
   - загрузка промпта;
   - вызов `call_llm`;
   - возврат результата.
3. Подключите новый шаг в `orchestrator/pipeline.py`:
   - импорт функции;
   - передача входов;
   - сохранение выхода в `steps`.
4. При необходимости обновите `runner.py` (например, новый флаг вывода).

## Как изменить логику пайплайна

В файле `orchestrator/pipeline.py` можно:

- менять порядок шагов;
- добавлять/удалять переходы данных;
- запускать альтернативные ветки;
- изменять формат агрегируемого контекста между шагами.

## LLM-интеграция

Сейчас используется абстрактный wrapper `utils/llm.py` в режиме `mock`.
Для реальной модели:

1. Измените `LLM_PROVIDER` в `config.py`.
2. Реализуйте ветку реального провайдера в `call_llm`.
3. Добавьте обработку ошибок/ретраев и логирование по вашей инфраструктуре.
